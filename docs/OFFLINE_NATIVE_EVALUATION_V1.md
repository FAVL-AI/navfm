## Accounting and timing

Every pair/draw is retained externally, including invalid outputs. All outputs and distance predictions must be finite; invalid rate denominator is all attempted draws, separate from expected/unattempted/returned slots. Each attempt/result uses a local atomic snapshot (serialize, sibling temporary file, flush/fsync, replace), preserving the prior parseable snapshot if interrupted; malformed output shape/cardinality is retained invalid, runtime exceptions halt with attempted identity/stage and existing results. An invalid draw makes that pair's expected metric incomplete rather than averaging only successful draws. Negative/action-invalid pairs never enter ADE/FDE; frozen role×pair×draw identities and duplicate/unexpected rejection bind the entire expected population; eligible and complete pair denominators are explicit; any incomplete eligible pair makes that trajectory summary mean null, not a survivor-only score. Per-role/training-seed/trajectory summaries keep seed variation separate from trajectory variation; four routes and their correlated anchors are not independent image replicates. Distance labels remain steps/categories, separate from metric XY errors.

Batch1 latency: two unscored native warmups per checkpoint, CUDA synchronize immediately before/after each forward or full ten-step DDPM sample.
