## Outcomes and small-sample decision

Common first-entry horizon: decisions 0..35 after kidnap. First lost-to-tracking transition is a confident declaration. Primary: selected node equals pose-nearest chain node at the predecision pose (Euclidean XY, lowest-index tie break). Secondary: absolute node error <=1, reported separately. Require ten subsequent preterminal decisions without lost re-entry; terminal/filler records never supply durability. Report follow-up pose-node correctness separately: no-reentry is not continuous exact localization.

Assign every efficacy attempt one primary category: correct confident (exact first declaration plus observed durable follow-up); wrong confident (non-exact first declaration, regardless of later correction or +/-1); abstention (no declaration and explicit non-arrival recovery halt); failure (no qualifying declaration, unstable/censored correct declaration, task budget exhaustion without an earlier qualifying primary outcome, crash or invalid/missing evidence). Once a correct first declaration has all ten required follow-up decisions, later task timeout does not reclassify that primary recovery outcome; report the timeout separately. Wrong-first applies only to a first declaration within indices 0..35; later wrong transitions feed the separate full-task guard. Keep failure subtypes and gate invalidation distinct. Durability censoring cannot become success. Preserve late declarations and all preterminal wrong confident transitions.

This four-pair sample is descriptive. A provisional favorable pattern requires R2 strictly more primary correct confident outcomes, no more wrong first declarations in the common horizon AND no more wrong confident transitions across the full preterminal task window than B1x. Report ties/adverse patterns without significance/generalization claims. Integrity failure yields INCONCLUSIVE, never an efficacy conclusion. No recovery-rate target is tuned using these outcomes.
