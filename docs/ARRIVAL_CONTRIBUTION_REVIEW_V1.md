## One proposed contribution candidate

**Research question.** On independent indoor layout groups, does an explicit goal-versus-distractor sequence verifier improve reliable arrival over the strongest admissible existing STOP method on the same frozen navigator, under RGB reference-route operation and balanced aliasing/illumination conditions?

**Task.** Reach the camera location that produced the final reference RGB and voluntarily stop within 0.5 m with the inherited settling requirement. A pre-recorded RGB chain is available equally to every arm. Reference creation is a declared cost and privilege; this is not single-image map-free navigation. The reference may use a separately declared teaching fixture, but live policy inputs contain RGB, timestamps and permitted reference identifiers only. Native IMU/wheel feedback belongs to low-level control, not localization, node selection or the verifier. Ground truth is confined to authorized initialization and evaluation; offline supervision derived from evaluator labels must be explicitly admitted before any verifier fitting. It is never a deployment observation.

**Candidate, deliberately simple.** With a frozen RGB pair matcher `s`, a four-frame current history and a reference chain `R[0:J]`, define `S_t(j) = mean(k=0..3) s(I[t-k], R[max(0,j-k)])`. Define terminal evidence `S_t(J)` and ambiguity margin `A_t = S_t(J) - max_j S_t(j)` over nonterminal reference windows. The terminal reference window and its exclusion from distractors are fixed before outcomes. A development-fitted, separately calibrated function `q_t = c(S_t(J), A_t)` proposes STOP only when `q_t >= theta` and `A_t >= margin` persist for a fixed one-second dwell. The released/adapted navigator and local controller are unchanged by this intervention. If evidence is insufficient, continue the same navigator until its fixed horizon or a safety abort; abstention is counted, not credited as success.

Reference sampling and observation history are both specified at 4 Hz. This exact-index sequence comparison assumes comparable reference/execution progression; speed or viewpoint mismatch can falsify it. Reference resampling/alignment must be fixed on development before freeze, never repaired after test access. Initial history fill does not duplicate one frame and pretend it is four independent observations. Matcher/encoder identity, calibration family, coefficients, thresholds, reference capacity and numerical tie rules remain freeze blockers. No method is implemented by this note.

**Mechanistic prediction.** Explicit competing-location evidence should chiefly reduce premature STOP on aliased routes; removing distractor competition or ordered history should remove that benefit. Better scalar calibration or merely waiting longer are rival explanations. The candidate fails as a contribution if a tuned distance/dwell rule, a single-image verifier or existing terminal belief matches it within uncertainty; if completion/time constraints fail; if the mechanism ablations retain its gains; or if its advantages depend on privileged pose, extra sensing, altered movement control or test tuning.

No replacement test geometry is created or opened here. If independent custody cannot be arranged, explicitly downgrade the later claim and reapprove the design before execution; do not fill the gate with a fictional person.

Proposed test population: 80 independent layouts, each with two base feasible start-goal tasks crossed with aliasing on/off and illumination shift on/off: eight feasible conditions per layout. Each layout also has two prespecified mismatched/absent-goal controls. Perturbations, severity, pairing and order are balanced before outcomes. Illumination is a proposed future factor only; the existing pause remains. Aliasing changes appearance while preserving route geometry and traversability; illumination changes photometry independently. Goal mismatch is its own stratum and never enters feasible-goal completion noninferiority. Texture/lighting changes do not increase independent sample size.

Each arm/seed receives the same initialized task, allowed observations and randomization block. Three fixed training seeds are averaged within layout; they do not multiply layout count. A released checkpoint repeated under three RNG blocks is not three independently trained releases. Diffusion uses one fixed reproducible RNG schedule, not outcome-selected sampling. All planned attempts stay in the accounting ledger. A provenance or measurement failure is not silently dropped/replaced; its reason and efficacy non-adjudicability are reported and the integrity gate halts further efficacy work. An unavailable wrong-location label is UNKNOWN, never zero; incomplete mandatory endpoints block efficacy adjudication rather than create a favorable valid-only sample. Emergency stops are distinct from voluntary arrival STOP, and remain completion failures. Contacts, moving distance/time and elapsed exposure are reported together because stopping early changes contact opportunity.

## Endpoints and falsifiable decision

The existing `wrong_stop` remains an aggregate failure of the inherited correct-stop test. The new **wrong-location voluntary STOP** is a separate endpoint, not a redefinition of that historical metric.

| Measure | Definition / denominator |
| --- | --- |
| Primary wrong-location STOP, `W` | Voluntary latched arrival STOP with evaluator distance from the goal-image capture position greater than 0.5 m. Denominator: every planned feasible-goal attempt, with complete mandatory measurement required for efficacy adjudication. A verified no-STOP episode is `W=0` but fails completion; it is not evidence of competence. Missing measurement is UNKNOWN. Boundary equality is inside. A later drift/settling failure remains distinct and the legacy aggregate is also reported. |
| Collision-free completion, `C` | Inherited correct stop: latch within 0.5 m, final distance within 0.5 m and motion less than 0.01 m during the final one-second settling window, with no contact during the decision episode. Reserve two seconds after the decision horizon solely for stop/settling observation; no new voluntary STOP after 120 seconds counts as in-budget completion. Tail contacts are additionally reported. |
| Restricted completion time, `T*` | Time to the qualifying collision-free correct STOP when achieved by 120 seconds; **assigned 120 seconds otherwise**, including wrong STOP, timeout, collision or abort. This is a capped outcome, not right censoring. Denominator: all planned feasible-goal attempts; the separate missing-measurement integrity gate still applies. |
| Arrival delay diagnostic | Among episodes that enter the goal region by 110 seconds, time from first evaluator-observed entry to qualifying STOP, capped at ten seconds; no qualifying STOP or competing failure receives ten seconds. Report entry frequency as well. This is explicitly conditional and cannot replace the all-attempt `T*` gate. |
| Contacts/exposure | Episodes with contact, contact count/severity definition, elapsed seconds and traveled distance; decision-period and post-stop-tail events separate. No safety claim from a reduced count without exposure accounting. |
| Runtime | Acquisition-to-command/STOP latency p50/p95/p99, missed deadlines, peak GPU/system memory, controller update/hold behavior and total inference work on each hardware tier. Resource thresholds must be qualified and frozen before test. |

Let each layout's endpoint be its balanced feasible-episode mean, first averaged across all three seeds. Let `Delta` be candidate minus champion. The joint proposed success claim requires all three gates: upper two-sided 95% CI for `Delta_W < -0.05`; lower CI for `Delta_C > -0.05`; and upper CI for `Delta_T* < +5 seconds`. Thus the reduction must exceed five percentage points with uncertainty, completion loss must be less than five points, and restricted time increase less than five seconds. These practical margins are proposals for Frank's scientific judgment, not measured effects. Strict boundary equality fails the relevant gate.

Compute paired layout differences and a layout-level paired interval, with a prespecified cluster-bootstrap sensitivity analysis. Resampling occurs at layout level with all routes/conditions/seeds kept together. No frame-, node- or diffusion-sample confidence intervals stand in for navigation uncertainty. Report raw per-layout/per-seed results, aggregate proportions, risk differences and intervals, including zero effects. The joint claim is an intersection-union test: each necessary gate can use one-sided alpha 0.025 without a Bonferroni correction across these three gates. Separate comparator or mechanism claims need their own declared hierarchy/Holm correction; otherwise they remain descriptive.

Simulation time governs the 4 Hz observation schedule, dwell, 120-second decision horizon, settling reserve and arrival delay. Wall time governs process timeout and actual acquisition-to-command latency. Clock provenance and real-time factor are reported separately. Contact means a qualified unintended robot/environment contact, excluding explicitly validated support wheel/floor pairs; an inherited fixture filter does not qualify arbitrary new scenes. No contact-free completion claim is admissible while contact observability is unqualified.

## Conditional sample calculation and finite resource envelope

There is no observed baseline wrong-location STOP rate or paired layout variance for this proposed population. The closed pilot cannot provide either. A five-point improvement may be impossible if the strong comparator's wrong-stop rate is already below five percent. Establish feasibility on development before test, without enriching or replacing test cases based on outcomes.

For a transparent normal approximation, `L = ceil(((1.959964 + 0.841621) * sigma_D / gap)^2)`, where `sigma_D` is the SD of paired **layout** differences. Planning assumes 80% marginal power for each endpoint, not 80% joint power. For wrong STOP, assumed true difference is -0.10 and the superiority boundary is -0.05, giving `gap=0.05`. For completion, assumed difference is 0 with boundary -0.05. For time, assumed difference is 0 with boundary +5 seconds. No value is an experimental result.

| Binary paired-layout SD / time paired-layout SD | Required layouts at these assumed gaps |
| --- | --- |
| 0.10 / 10 seconds | 32 |
| 0.15 / 15 seconds | 71 |
| 0.20 / 20 seconds | 126 |

Eighty test layouts suffice only for this approximation when each relevant SD is at most 0.1596288 (binary endpoints) or 15.96288 seconds (time). A separately held development pilot must support conservative upper SD bounds and an appropriate small-sample/discrete-outcome power simulation before freeze. Its uncertainty, attainable event floor and the joint-power deficit may require more layouts than this example. A finite sample of 80 is **not** approved, guaranteed powered, or made adequate by adding frames/seeds. If the required layout count/resource envelope is infeasible, redesign or report an underpowered exploratory study before test access; never relax the margin after results.

## Discriminating diagnosis and evidence tiers

The cadence question is a separate development-only intervention: replay the same physical path with controlled timestamp/history sampling at 3 Hz and 4 Hz while holding checkpoint, source frames available to each condition, goal/reference, action normalization and controller timing fixed as appropriate to the tested cause. Separately compare labels expressed as frame counts versus elapsed seconds, with raw-to-processed timing mappings verified. If changing physical motion or reference progression is necessary, use a declared factorial experiment rather than attribute the combined change to cadence. Teacher displacement of 0.05 m per frame is not automatically 0.05 m/s. No cadence diagnosis may tune the sealed 4 Hz confirmatory test.

For waypoint/arrival divergence, first score the same admitted offline inputs with frozen heads and identical native reduction. Then, only after plant qualification, hold navigator waypoints/controller fixed while replacing the stop decision. This distinguishes a changed stopping policy from improved movement. A reduction in offline waypoint error or temporal-distance MAE alone cannot decide the closed-loop hypothesis.
