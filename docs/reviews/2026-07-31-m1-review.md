Evaluation of the three findings
Finding 1 — Broken documented reproduction command
I would classify this as:
Specification–Execution Mismatch
The repository claimed:

```
Run:

bash gates/M1/reproduce.sh

```

The repository actually required

```
PYTHON=.venv-m1/bin/python \
bash gates/M1/reproduce.sh

```

That is not a documentation typo.
It is a failed reproducibility claim.
Your fix is exactly correct because it preserves two important invariants:

* never infer execution state;
* never silently change interpreters.

The temptation to "help the user" by auto-discovering Python would actually weaken scientific reproducibility.
Instead you now have:

```
requirements absent

↓

abort

↓

state exactly what is missing

```

That is much stronger.
