## PlaceNav fidelity contract

Use `PlaceRecognitionTopologicalFilter` with **released CLI** `delta=10`, `window_lower=-1`, `window_upper=2`. The class constructor instead defaults to `5,-2,10`; silently using those defaults would qualify a different configuration. Initialization computes descriptor distances `sqrt(2-2 Dq)`, the 2.5% and 97.5% quantiles, and `lambda=log(delta)/(q97.5-q2.5)`, then normalizes `exp(-lambda*d)`. Each match performs the native symmetric-padded convolution followed by the exponential observation likelihood and normalization. Preserve exact slice boundaries and first-index `argmax` tie handling.

The native navigation loop initializes from its first valid observation and then calls `match` on that same observation. The fixture must distinguish this from emitting the unpropagated initial posterior. The native filter neither clips cosine similarities nor handles a zero quantile gap. Normalized, finite, dimensionally valid descriptors alone do not guarantee a defined initialization. Outside the native finite domain, the wrapper must reject the input or report unsupported numerical behavior; inserting epsilon, clipping, smoothing or a uniform prior would be a mathematical adaptation, not parity.

The native arrival predicate is `closest_node_idx == goal_node_idx`. Navigation publishes the current waypoint, publishes the arrival Bool, then returns. The released controller subscribes to that Bool, publishes zero `Twist` and returns. This establishes the source-level command chain; it does not measure physical stopping. The requested goal is an existing reference node (default: final node). Arbitrary absent goal images are not a supported native input.

## ULVN fidelity contract

The **ROS `BPL & BASS/bass.py` implementation** is the online-native target. Its `PlaceRecognition` uses `max_steps=3`, `delta=5` and row-normalized `I+A+A²+A³`, retaining supplied adjacency weights and walk multiplicity. It clips descriptor dot products before the square-root distance, but does not normalize the input descriptors itself. Equal initial distance quantiles set `lambda=1`. It explicitly initializes before matching; it has no implicit `match` initialization or general zero-sum fallback.

For each observation it computes normalized entropy of the **previous posterior**, clipping probabilities to `[1e-10,1]` inside the logarithm. Prediction/observation weights are `(0.3,0.7)` above entropy 0.7, `(0.6,0.4)` below 0.3, and `w_prediction=0.6-0.75*(entropy-0.3)` between them. It normalizes the graph prior and observation likelihood, takes their weighted geometric product, and normalizes again. The returned localization is posterior `argmax`; the online caller discards confidence. These constants, edge cases and operation order are source behavior, not calibration parameters.

The reusable `ulvn_core/navigation.py` is materially different: it binarizes positive adjacency entries, converts/normalizes descriptors, initializes implicitly in `match` and supplies additional fallbacks. Testing that class against a wrapper is insufficient to claim parity with the released ROS loop. A binary graph may hide the transition discrepancy; a weighted synthetic graph must expose it in the source-fidelity checks.

Native BASS localizes both the goal image and current image against the supplied reference descriptors, then plans a path. Selecting `--goal_image_index` does not bypass this goal recognition step. Preserve `initial_localize`, its tie behavior, and `next_subgoal(..., n_ahead=2, replan_if_offpath=True)` when qualifying the terminal condition. The ROS condition is `subgoal_idx == goal_idx and current_idx == goal_idx`; it sets a persistent arrival flag. A missing subgoal skips arrival publication even when that flag was already set. Stored flag state must therefore be distinguished from a newly publishable arrival/STOP proposal. On an ordinary valid path the conjunction usually agrees with MAP goal equality, but that simplification must not replace the planner/latch semantics in the qualified interface.

**Native observable: arrival Bool, not demonstrated actuator STOP.** The [released launcher](https://github.com/hren20/ulvn/blob/e2f47fe3e2757a1ebdc041f4364dddd26a19f9f5/BPL%20%26%20BASS/launch_ulvn.sh) starts the global and local planners. The local planner subscribes to RGB and the selected goal path, does not consume the arrival Bool, and continues producing waypoints. The external controller mentioned in reproduction instructions is not included in that released stack. Converting the Bool into common-controller STOP is an explicit adapter requiring separate integration qualification.

## Common admissibility and parity scope

The descriptor fixture supplies only reference descriptors, observation/goal descriptors and an explicitly synthetic reference graph. No true pose, distance, heading, depth, collision labels or simulator state may enter the decision interface. Synthetic ground truth may define an expected test outcome outside the interface. For any eventual RGB experiment, graph construction must use the same permitted reference collection and temporal order, without privileged ground-truth connectivity or extra map exposure. This component check does not validate an RGB graph builder.

The faithful oracle executes unchanged AST-extracted native classes/functions from the authenticated external files. PlaceNav's database and image-extractor I/O may be replaced by synthetic descriptor providers; this substitution is the declared test boundary. ULVN's native planner/normalization must remain native even where its reusable core differs. Hash checks must precede extraction. No upstream module launcher, model loader, network download or ROS initialization is executed.

Qualification compares the complete initialized and updated posterior sequence, likelihood scale, native MAP and planner/arrival state against the direct native oracle. It must cover nonuniform weighted graph transitions, ambiguity and tie behavior, reset/replay isolation, first-frame ordering, persistent arrival, missing subgoal, dimension/nonfinite/zero input rejection and source-byte tampering. Preserve admitted floating-point input dtypes or explicitly restrict the tested domain; accepting float32 inputs and silently converting them to float64 does not establish exact parity with native float32 arithmetic. Comparing only final STOP, normalized sums, or a separately rewritten generic Bayes formula is insufficient. If both adapter and oracle delegate the same native functions, passing establishes correct binding and lifecycle only; it is not an independent mathematical proof of the upstream algorithm. Continuing the PlaceNav filter recurrence after its arrival predicate fires is an isolated component stress check; the native navigation program would already have returned.

Timestamps are an adapter admission control: require the declared ordered observation sequence and reject duplicate/backward or malformed timing. The native belief recurrences are per update and do not use elapsed seconds. PlaceNav config runs at 5 Hz; ULVN's ROS loop requests 30 Hz and does not enforce a fresh frame on every update. A future common 4 Hz, one-update-per-new-frame interface is therefore a cadence adaptation. Descriptor parity does not justify a claim of cadence invariance or performance equivalence across those rates.

For native mapped goals, goal identity must arise from the permitted reference input and the corresponding native goal contract. Arbitrary or mismatched goal images cannot be forced onto a convenient valid node and labeled faithfully supported. The 108 passive admission slots in the development design remain passive; absent-goal admission and any common rejection mechanism require separately frozen contracts. No invented wrong-stop or completion outcomes fill unsupported slots.

## Permissible claim and remaining blockers

A passing bounded check supports only: **the adapter reproduces the pinned native descriptor-level belief and declared arrival semantics on the admitted synthetic fixtures**. It does not qualify VPR encoder preprocessing/weights, learned feature quality, reference construction, NoMaD checkpoint execution, RGB inference budgets, 4 Hz performance, wrong-stop reduction, completion, contacts, latency on Orin, generalization, or scientific novelty.

The fixed NoMaD family remains seeds 0/11/22 with exact admitted identities required before system use. Hash-only binding may stream checkpoint bytes to verify integrity against admitted records; it does not deserialize a model, execute inference, validate encoder behavior or qualify navigation. The descriptor checks do not load these checkpoints into a model. The unqualified sphere plant, undecoded CAD, motion/controller qualification, observable unintended contacts, matched-reference integration and unsupported native absent-goal interface remain explicit gates. No comparator may be replaced by a weaker fallback to clear a gate. No feasibility trial, calibration sweep, cadence/illumination experiment, simulator run or robot actuation follows automatically from source qualification.

The bounded implementation readback and corrective readback are complete. The corrected packet preserves float32/float64 descriptor arithmetic, compares initialized beliefs and likelihood scales, runs an independent native BASS planner/state trajectory, tests duplicate-descriptor goal rejection, separates a stored arrival latch from skipped publication, and validates reference identities and observation order. It is accepted for the proposed frozen synthetic component probe. Hermetic software guards are separate evidence; the measured native probe result must be recorded in the [qualification record](STOP_INTERFACE_QUALIFICATION_V1.md) after execution. This acceptance neither asserts that the positive probe has already passed nor clears any full-system or study gate.
