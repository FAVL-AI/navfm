# Fixed offline numerical diagnostic v1

Scope: preserved observer-window v2 reference/replay images, original pinned CUDA model/runtime, development case A/s_bend_run_0000 only. No simulator import/start, new capture, post-kidnap decision, recovery efficacy, threshold tuning or existing-attempt reclassification. Existing freezes and failed numerical gates remain immutable.

Two fresh sequential worker processes (`offline-numerical-v1-p1`, `offline-numerical-v1-p2`) are the entire manifest. Each runs 28 isolated calls: seven saved reference pre-invocation states at physical steps 0/6/12/18/24/30/36, reference/replay image inputs, two repeats. For each step, order is repeat 1 reference/replay then repeat 2 reference/replay. Each then runs one full seven-invocation sequence per input arm (reference then replay), initialized from the same saved reference initial state. Total ceiling: 2 processes, 84 policy/model calls. There is no warmup, adaptive repetition, retry or replacement. Each process has a 600-second watchdog; any execution/provenance/input-identity failure halts expansion. Numerical disagreement is an observation, not an execution failure, and does not select further runs. STOP after this manifest.

Isolated calls restore every declared dataclass field (including history, pending/lost/scan/attempt counters), wrapper counters, and the exact saved search-window/config/checkpoint/backend/chain schema. Configuration dataclasses remain the original constructed objects and must agree. The common seeded (0) Python/NumPy and post-model-initialization Torch CPU/all-CUDA RNG state is restored for each isolated call and each sequence start, checked by digest. Full sequences subsequently retain their own evolving state/RNG. Model remains eval; original numerical flags are read back, never changed. Saved image and asset hashes are checked before/after; actual model-entry tensor bytes, dtype/shape, raw outputs, full before/after policy state and prediction are recorded. Unknown state, nonfinite output, missing/extra model entry, unsupported runtime or drift fails closed. No policy command is executed.

Three comparisons are fixed before inference:

1. Within/fresh-process same-input isolated repeats: require identical actual model-entry tensor hashes and restored state/RNG to attribute any output variation to execution under this recorded environment. Report bitwise tensor/output equality separately from the immutable numerical tolerance (absolute 0.001, relative 0.00001), discrete outputs and requested commands.
2. Reference/replay isolated calls: identical restored reference state/RNG/model, differing preserved inputs. Compare every step; this isolates an input-associated effect only if same-input repetitions are stable within the stated criterion. If execution also varies, input attribution remains confounded. Tensor differences are measured, not assumed from file identity.
3. Full seven-step sequences: within each process compare arms and across processes compare each arm. Report first numerical/discrete/command divergence and complete state accumulation, including stored distance history. A sequence difference alone does not separate immediate input effects from accumulated state.

Record argmin winner/runner-up gap and signed minimum-distance margins to close, bounded lost-enter/exit and recovery-exit thresholds, plus requested-goal close margin. These are descriptive margins at the actual policy window, not robustness guarantees; discrete state logic/counters and command differences remain explicit.

Mutually achievable criteria are separate: (a) bitwise repeated tensor/output equality, (b) numerical output/state agreement under the existing tolerance, (c) identical discrete decisions, and (d) command agreement under that same numerical tolerance. Failure of a stronger criterion does not imply failure of every weaker criterion. No aggregate new PASS overrides the existing handover FAIL. Image grayscale MAD below 2.5 has no established implication that outputs stay within 0.001; this diagnostic measures compatibility for these inputs only. A future task-relevant criterion would need independent rationale/validation before outcomes, not fitting this result.

Freeze source/config/input manifest before all inference. Preserve all attempts, settings, failures and raw results externally. One bounded interpretation review follows results. Held-out geometry stays sealed, illumination paused and robot actuation unauthorised. No further run follows automatically.

Original saved traces did not record all backend numerical flags; this offline diagnostic records actual readbacks, but cannot establish identical global CUDA/library history to the earlier simulator process. Model-entry hooks copy tensors/outputs to CPU for evidence; their synchronization can differ from the earlier uninstrumented process. No deterministic-algorithm or precision flag is changed.
